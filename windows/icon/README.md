# 图标（默认与替换）

本目录提供默认应用图标：

- `dsh.ico` —— 多尺寸 ICO（16/32/48/64/128/256），可直接用于 Windows 快捷方式
- `dsh-1024.png` —— 1024 母图，方便二次编辑

默认图标为**原创绘制的鲸鱼吉祥物**（非 DeepSeek 官方标识），随仓库以 MIT 许可分发，可放心使用。

## 素材体检（无眼睛也能查）

生成或找到新图标素材后，先跑一键体检：

```bash
node check-icon.mjs <图片路径>
```

自动检查：格式/正方形、不透明与半透明占比、背景类型（透明 / 纯色 / 满幅成品）、背景马赛克纹理。全绿即可交给处理管线生成多尺寸 ICO。

## 替换图标：只需换一个文件

1. 准备你自己的 `.ico` 文件（推荐含 16~256 多尺寸）
2. **直接覆盖本目录的 `dsh.ico`**（保持文件名不变）
3. 若桌面快捷方式已指向该文件，刷新桌面（F5）即生效
